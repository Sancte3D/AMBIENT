# AMBIENT Project Baseline

Use this as orientation, then verify it against `PROJECT_STATUS.md`, the current schematic generator, the current linker map, and the current firmware.

## Product

- Portable tactile ambient instrument intended to reduce screen dependence.
- No Bluetooth or Wi-Fi.
- Primary interaction: five Kailh Choc cell keys, five modifier buttons, four encoders, LEDs, two speakers, phones/line out, MIDI out, and a compact color LCD.
- The display supports the instrument. It must not turn the product into a menu-heavy miniature computer.

## Current display target

- Default panel: Waveshare 1.9-inch ST7789V2 IPS, 170 × 320 physical pixels, used in landscape as 320 × 170.
- Optional panel selector: 2.0-inch ST7789, 240 × 320 physical pixels, used in landscape as 320 × 240.
- Keep the 1.9-inch panel as default until the exact 2.0-inch module, pin order, active area, outer dimensions, and procurement path are physically verified.
- Current H743 pins: PA5 SCK, PA7 MOSI, PA6 CS, PC4 D/C, PC5 reset.
- Backlight: PCA9685 channel 15 drives the LCD backlight path through Q2 2N7002. Verify the latest generated schematic before editing.

## Current firmware path

- Active firmware: `field-ambience-current/firmware-c-next/`.
- H743 driver: `src/hal_h743/lcd_st7789_h743.c`.
- Shared display API and panel constants: `include/oled.h`.
- Color conversion: `include/oled_color.h` and the corresponding source.
- Host display simulator: `tools/display_sim.html`.
- Hardware test: `tools/display_hw_test.c`.
- The current visual pipeline stores a compact 4-bit grayscale framebuffer and applies an accent tint while converting to RGB565.
- The H743 implementation uses SPI1 at 30 MHz and an asynchronous row-pipelined DMA flush with two aligned line buffers. Inspect the current file before changing this statement.
- Display DMA priority must remain below the audio refill DMA priority.

## Performance reality

At 30 MHz SPI, ignoring command and scheduling overhead:

| Region | RGB565 bytes | Wire time |
|---|---:|---:|
| 320 × 170 full frame | 108,800 | 29.0 ms |
| 320 × 40 strip | 25,600 | 6.83 ms |
| 80 × 80 tile | 12,800 | 3.41 ms |
| 48 × 48 tile | 4,608 | 1.23 ms |

Use `time = width × height × 2 × 8 / spi_hz`.

The latest documented r19.41 memory report showed approximately FLASH 11%, D1 74%, D2 86%, and DTCM 91%. These numbers can change. Read the latest map before allocating another framebuffer or large animation asset.

## PCB rules

- The KiCad schematic is generated by `field-ambience-current/kicad/generate_kicad_project.py`.
- Never hand-edit generated `.kicad_sch` files.
- The documented stack is four layers: signal / solid GND / +5 V / signal. Verify current status before layout.
- The LCD module connection is mechanically critical. Verify the actual module header order and active-area position before fabrication.
- Apply the root AI-ready schematic standard and anti-guess rule to every component and footprint.

## Visual direction

- Calm, instrument-like, minimal, deliberate, and original.
- Strong silhouette and hierarchy; avoid generic dashboard styling.
- Primarily black, white, and gray with one controlled world accent.
- Avoid washed-out color. Accents should remain visibly saturated while occupying limited area.
- Use motion to explain state or continuity, not as decoration.
