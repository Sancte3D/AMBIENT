# Synths_Archive

The six legacy manual synth engines are archived by product decision (2026-10-04).
They are retained unchanged, including symbols and scene IDs, for compatibility
and regression testing. Build lists, lint and render tools follow this location.

This is a source archive, not yet removal from the linked firmware or menus.
No RAM saving is claimed. Runtime removal requires an explicit scene migration
and replacement of manual cell routing with the active World palette.

Do not treat these engines as the sound palette for the new World system.
