# Package 2a — Live Equal/Just switching in the six V2 synths

Previously engine_set_tuning only changed future note conversion. Held cells
kept their previous frequency. Replaying note_on would restart envelopes and
could reorder last-note priority, so this patch adds a pitch-only retune_hz
callback through the device backend, synth host and six native cores.

Each core changes only its existing frequency target and uses its native
glide. Phases, gates, envelope states, velocity, filter attacks and Storm's
attack bend are not reset. All held synth source frequencies are updated,
including covered notes; only the top source drives the mono core. Tuning
ratios preserve fine detuning already present in the input frequency.
Repeated selection of the same tuning is a no-op. Old backends without the
optional callback continue to affect future notes only.

Scope: six V2 cores, both physically held and HOLD-latched cell sources.
Ambient pad/Bowed/Horn/Choir and generated sustained notes still need their
own pitch-only paths (package 2b). Existing release/FX tails are not repitched.
No new audio buffers or per-sample work. Bounded control-side conversion uses
64 bytes of local reference storage; added callback pointers reside in the
existing const vtables. Hardware H743 build/map and DWT qualification remain
separate gates; host success does not prove a device deadline.

Validation: full bash test/run_tests.sh exit 0, 16406 device checks and
478860 effects checks, zero failures, hot-path lint clean. New regression
checks non-numeric press order, covered-note fallback, repeated mode changes,
no attack callback during retuning, and idle switching. Twelve rendered PCM
cases cover both directions across all six cores: the requested fundamental
has at least 14.32x the old-frequency spectral energy (required >2x).
This verifies retuning, not subjective timbre quality or precise cents.

Audio: Ambient_Equal_Just_AB.wav (13 s, stereo 44.1 kHz 16-bit), generated by
tools/render_tuning_review.py with old/new host libraries. First six seconds
before; after starts at 7 s. Each section holds FM Glass E5 over a quiet C5
reference: starts Just, changes to Equal after 2 s, back to Just after 4 s.
Identical gain, no FX, peak 0.4375; host rendering, not a device recording.
